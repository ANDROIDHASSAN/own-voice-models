Poora project ek nazar mein

ek token ka safar, shuru se aakhir tak

LLM jaadu nahi hai. Wo ek function hai: ab tak ke tokens andar, agle token ki probability bahar. Text banta hai kyunki hum ye function baar-baar chalate hain.

Model sach mein kya "sochta" hai

Ye do chart hamare train hue model ke asli output hain. Har bar ek possible agla token hai, lambai uski probability.

Seedhi bhasha mein

Model ek shabd nahi "jaanta". Wo har baar 4,096 tokens ko number deta hai, aur hum unme se ek chunte hain. Jab wo pakka hota hai to ek bar lamba hota hai; jab nahi hota to kai chhote.

1

Autograd: network seekhta kaise hai

autograd.py · pure Python, koi library nahi

Poori deep learning ek hi loop hai: andaza lagao, dekho kitna galat tha, har weight ko thoda sahi disha mein khiskao. Ye chapter wo loop sabse chhote roop mein banata hai.

Seedhi bhasha mein

Socho tum andhere mein pahaad se neeche utar rahe ho. Tum pair se zameen ka dhalaan mehsoos karte ho aur neeche ki taraf ek kadam lete ho. Dhalaan = gradient. Kadam ka size = learning rate. Oonchai = loss. Bas yahi training hai.

Chaar step jo kabhi nahi badalte

StepKya hota haiCode mein
Forward passInput ko network se guzaar kar prediction nikalnanet(x)
LossEk number: prediction kitni galat hai(net(x) - y) ** 2
Backward passHar weight ka gradient nikalnaloss.backward()
UpdateWeight ko gradient ke ulte taraf khiskanap.data -= lr * p.grad
Naapa hua

Gradient check: hamara backprop 0.084245 deta hai, aur "nudge karke dekho" tareeka bhi 0.084245. Dono barabar, yaani engine sahi hai.

XOR: 1000 step mein loss 0.478 se 0.0000. Predictions [0, 1, 1, 0].

Sach baat

Pehli baar learning rate 0.1 pe loss ghatne ki jagah infinity ho gaya (divergence). 0.05 pe theek chala. Ye sabse aam training bug hai: step itna bada ki ghaati ke paar kood gaye.

Interview mein bolo

"Backpropagation is just the chain rule applied over a computation graph in reverse topological order. I implemented a scalar autograd engine myself and verified it with a finite-difference gradient check before moving to PyTorch."

Code mein kahan

class Value ek number + uska gradient. _backward har operation ka local chain rule. def backward poore graph pe ulta chalna. class MLP wahi cheez jo har transformer block ke andar hai.

2

Tokenizer: text se numbers

tokenizer.py · byte-pair encoding (BPE), scratch se

Model akshar nahi padh sakta, sirf numbers. Tokenizer tay karta hai ki "ek tukda" kya hai. Ye faisla model ki quality pe seedha asar daalta hai.

TareekaFaydaNuksaan
Har akshar ek tokenVocabulary bahut chhotiSequence bahut lambi, seekhna mushkil
Har shabd ek tokenSequence chhotiLakhon shabd, naya shabd aaya to fail
Subword (BPE)Beech ka raasta, har LLM yahi leta haiTokenizer ko pehle train karna padta hai
Byte-level kyun

256 bytes se shuru karne ka matlab: duniya ka koi bhi text encode ho sakta hai. Emoji, naya shabd, galat spelling, kuch bhi. "Unknown token" kabhi nahi aata.

Special tokens

<|bos|> <|eos|> document ki shuruaat aur ant. <|hi|> <|mr|> <|hing|> bhasha ka tag: isse hum model ko batate hain kis bhasha mein likhna hai.

Interview mein bolo

"I wrote a byte-level BPE tokenizer. It starts from 256 bytes so nothing is ever out of vocabulary, then greedily merges the most frequent adjacent pair. I pre-tokenize into words and keep a pair-to-words index, so each merge only touches the words that contain that pair."

4

Model: transformer ke andar

model.py · 12,194,688 parameters

Transformer do cheezon ko baar-baar dohraata hai: attention (tokens ek doosre se jaankari lete hain) aur feed-forward (har token akele sochta hai). Dono ke saath ek skip connection.

Seedhi bhasha mein

Socho ek meeting hai. Attention = sab ek doosre ki baat sunte hain aur zaroori cheez note karte hain. Feed-forward = har koi apne notes pe akele sochta hai. Ye do kaam 6 baar hote hain, aur har baar samajh thodi gehri hoti hai.

Attention, tukdon mein

√head_dim se bhaag kyun

Bade vectors ka dot product bada hota hai. Bade numbers pe softmax ek hi token ko 100% de deta hai aur baaki sab 0. Tab gradient mar jaata hai. Bhaag dene se numbers kaabu mein rehte hain.

Multi-head kyun

Ek head ek hi rishta pakad sakta hai. 6 heads alag-alag cheezein dekhte hain: kaun subject hai, kaunsa quote khula hai, pichhla shabd kya tha.

Interview mein bolo

"It's a pre-norm decoder-only transformer with the modern Llama-style choices: RoPE instead of learned positions, RMSNorm instead of LayerNorm, SwiGLU instead of GELU, no biases, and tied input and output embeddings. I wrote attention by hand instead of calling scaled_dot_product_attention so I could record and inspect the attention weights."

Code mein kahan

Hyperparameters

384d_model: har token ke vector ki lambai
6n_layer: blocks
6n_head: har block mein heads (har ek 64 ka)
256ctx: ek baar mein kitne tokens
Kaise pata code sahi hai

check.py ye sab test karta hai, aur sab pass hain:

  • Causality: baad ka token badalne se pehle ki predictions nahi badalti. Mask sahi hai.
  • Loss: haath se likha cross-entropy PyTorch wale ke barabar hai.
  • KV cache: ek-ek token dene pe wahi logits aate hain jo poori sequence dene pe.
  • LoRA: naya adapter kuch nahi badalta; merge karne ke baad output wahi rehta hai.

Training self-supervised hai: kisi ne kuch label nahi kiya. Har position ka sahi jawab text ka agla token hi hai.

Pehla loss 8.32 kyun hona chahiye

Bina seekha model har token ko barabar chance deta hai: 1/4096. Uska loss −ln(1/4096) = 8.32. Agar pehla loss isse bahut alag aaye to code mein bug hai. Ye sabse sasta sanity check hai, aur interview mein ye batana bahut achha lagta hai.

Teacher forcing

Training mein model ko hamesha sahi pichhle tokens milte hain, uske apne galat andaze nahi. Aur causal mask ki wajah se 256 tokens ki ek sequence 256 examples ban jaati hai.

Perplexity

exp(loss). 6.5 ka matlab: har kadam pe model utna unsure hai jitna 6-7 barabar options mein se chunte waqt hota. Random model ka 4,096 hota.

Interview mein bolo

"Training is next-token prediction with cross-entropy. I use AdamW with weight decay only on the matrices, linear warmup then cosine decay, and gradient clipping at 1.0. I sanity-checked that the initial loss was ln of the vocab size, and I track validation loss on held-out documents to catch overfitting. It went from 8.37 to 1.88."

Sach baat

Val loss aakhir tak gir raha tha, yaani training rokne ka waqt nahi aaya tha: hamne bas 4000 pe rok diya. Zyada iterations ya zyada data se model aur behtar hoga.

KV cache: wahi jawab, kam kaam

Seedhi bhasha mein

Bina cache: har naye token ke liye model poori kahani shuru se dobara padhta hai. Cache ke saath: purane tokens ke keys aur values yaad rakhe jaate hain, aur sirf naya token process hota hai. Jawab bilkul same, check.py ye test karta hai.

Model ne asal mein kya likha

एक दिन राजू ने अपनी माँ से कहा कि वह जंगल में घूमने जाएगा। सभी जानवर बहुत उत्साहित थे। राजू ने सोचा, "क्यों न मैं भी उनके साथ खेलूं?"

एकदा एक लहान मुलगा होता, ज्याचे नाव आर्यन होते. आर्यनला समुद्रकिनाऱ्यावर खेळायला खूप आवडत असे. एक दिवस, तो समुद्राच्या किनाऱ्यावर गेला.

kya chal raha hai bhai? → kuchh nahin yaar, bas aaram karna hai.

weekend ka kya plan hai? → bas ghar pe relax karna hai, aaram karne ke liye.

Sach baat

Grammar theek hai, par kahani ka logic toot-ta hai: Raju akela jaane ki baat karta hai, phir achanak "sabhi jaanwar utsaahit" ho jaate hain. Model shabdon ka pattern jaanta hai, duniya nahi. Isi ko bade models mein hallucination kehte hain.

LoRA: 1% se kam weights se fine-tune

lora.py · 20 sawaal-jawab, 600 steps

Pre-training bhasha sikhati hai. Fine-tuning us model ko ek kaam, domain ya personality ke liye dhaalti hai. LoRA ye bina original weights chhue karta hai.

Fine-tune se pehleBaad mein
Train hue parameters—110,592 of 12.2 M (0.91%)
Persona loss4.580.32
General val loss1.8291.888 (+0.06, thoda bhoola)
"tera naam kya hai?"mera toh bas normal hi hai.mera naam Chhotu GPT hai.

Seedhi bhasha mein

Poori kitaab dobara likhne ki jagah, uske haashiye mein chhote notes chipka do. Kitaab wahi rehti hai, notes use naya kaam sikha dete hain. Notes ki file 100 guna chhoti hai.

Rank kya hai

A aur B kitne "patle" hain. Rank 8 ka matlab badlaav 8 dishaon tak seemit hai. Maanyata ye hai ki ek naye kaam ke liye zaroori badlaav simple hota hai, chahe model khud complex ho.

Sach baat: teen cheezein jo galat gayi
  • Bhoolna. Pehli koshish mein general val loss 2.70 se 3.19 ho gaya (catastrophic forgetting). Har step mein purane data ka ek batch jodne se (replay) ye kaafi kam hua.
  • Kam training. 300 steps pe model ne apna naam "Mhhotu GTP" likha. 600 pe sahi aaya.
  • Ratta. Persona aam baat mein ris gaya: "kya chal raha hai bhai?" ka jawab aaya "kuchh nahi yaar, bas phone pe scratch se banaya gaya." 20 examples samajhne ke liye kam hain.
Interview mein bolo

"LoRA freezes the pretrained weights and learns a low-rank update B times A on the attention matrices. B is initialized to zero so training starts from the original model. I trained 0.91% of the parameters, the adapter is 0.45 megabytes, and after training I merge it back so inference cost is unchanged. I also saw catastrophic forgetting and reduced it by replaying original data."

Quantization: phone ke size tak

shrink.py · weights ko kam bits mein rakhna

Weights 32-bit floats mein train hote hain. Unhe itni baareeki ki zaroorat nahi hoti. Kam bits mein rakhne se model chhota hota hai; sawaal ye hai ki kitna nuksaan hota hai.

Seedhi bhasha mein

3.14159 ko 3.1 likhna. Har number thoda galat ho jaata hai par jagah bahut bachti hai. int8 mein har weight −127 se 127 ke beech ka ek poora number ban jaata hai, saath mein ek scale jo use wapas float banata hai.

TermMatlab
PTQ (post-training)Train hone ke baad quantize karna. Hamne yahi kiya.
QAT (quantization-aware)Training ke dauran hi quantization ka asar dikhana. Zyada mehnat, kam nuksaan. Gemma ka QAT version yahi hai.
Per-tensorPoori matrix ka ek scale. Simple.
Per-channelHar row ka apna scale. Chhote weights wali row bade weights wali row ki wajah se nahi pisti.
Sach baat

Pehli baar chaaron rows mein loss bilkul same aaya (1.8448) aur laga code mein bug hai. Jaanch ki to pata chala int8 ki galti weight ke size ka sirf ~1% hai, isliye loss sach mein nahi hilta. Tab 4, 3 aur 2 bit jode taaki dikhe ki kahan toot-ta hai. Seekh: "kuch nahi badla" ko pehle shak se dekho, phir naap ke maano.

Interview mein bolo

"I did post-training quantization and measured validation loss on identical batches. int8 was free, 12 megabytes instead of 49. At 4 bits per-channel scaling lost 0.03 while per-tensor lost 0.12, and at 2 bits the model collapsed. So the practical floor for this model is around 4 bits with per-channel scales."

X-ray: model ke andar jhaankna

xray.py · tokens, belief, attention

Jo model tum dekh sakte ho, wahi tum samjha sakte ho. Ye asli attention map hai, hamare train hue model se, jab wo "एक दिन राजू ने अपनी माँ से कहा" padh raha tha.

Seedhi bhasha mein

"कहा" ke baad kya aayega ye tay karne ke liye model "से" aur "ने" ko dekhta hai: yaani wo vaakya ka dhaancha pakad raha hai (kisne, kisse). Kisi ne use grammar nahi sikhayi; ye agla token predict karte-karte khud ubhra.

Sach baat

Attention map dekhkar kahani banana aasaan hai aur galat bhi ho sakta hai. Ye 6 heads ka average hai, aur attention weight "kaaran" nahi hai, sirf "kahan dekha". Interview mein ise interpretability ka pehla kadam kaho, saboot nahi.

Chalao

python xray.py --lang hi --prompt "एक दिन राजू ने अपनी माँ से कहा" teen cheezein dikhata hai: tokens, agle token ki probability, aur har layer ka attention.

Ablation: unke do ideas, hamare model pe naape

Ablation study = ek cheez badlo, baaki sab same rakho, aur naapo. nanochat ke do ideas liye: QK norm (query aur key ko barabar lambai ka karna) aur zero-init (har block shuru mein "kuch nahi" karta hai).

Sach baat

Ye ek seed aur sirf 500 iterations hain. Fark chhota hai, aur alag seed pe kitna hilta hai ye naapa nahi gaya. Ye bhi nahi pata ki 4000 iterations ke baad fark bachta hai. Isliye main model abhi baseline hi hai.

Interview mein bolo

"I compared against the source of nanoGPT, nanochat and minimind. I took two ideas from nanochat, QK norm and zero-init projections, and ran an ablation: together they improved validation loss by 0.085 at 500 iterations. It's one seed and a short run, so it's a promising signal, not a proven result."

Interview: sawaal aur jawab

"BOLO" wali line English mein seedhe boli ja sakti hai
30 second ka pitch

"I built a decoder-only transformer from scratch in PyTorch to really understand how LLMs work. I wrote my own byte-level BPE tokenizer, multi-head causal self-attention with RoPE, RMSNorm and SwiGLU, and a training loop with AdamW, warmup, cosine decay and gradient clipping. I trained a 12 million parameter model on Hindi, Marathi and Hinglish, taking loss from 8.37 to 1.88. Then I added a KV cache, LoRA fine-tuning and int8 quantization, and wrote tests for causality and cache correctness."

A. Buniyaad

LLM asal mein kya karta hai?
It predicts a probability distribution over the next token given all previous tokens. Text is generated by sampling one token and feeding it back in.

Bas agla token. Baaki sab (jawab dena, kahani likhna) isi ko baar-baar chalane se aata hai.

Token kya hai? Shabd kyun nahi use karte?
A token is a subword unit. Word-level needs a huge vocabulary and fails on unseen words; character-level makes sequences too long. Subwords are the trade-off.

Aam shabd ek token, mushkil shabd tukdon mein. Naya shabd bhi purane tukdon se ban jaata hai.

BPE kaise kaam karta hai?
Start with bytes as the vocabulary, repeatedly merge the most frequent adjacent pair into a new token until you reach the target vocabulary size.

Hamne 3,835 merges kiye. Encode karte waqt merges usi order mein lagte hain jis order mein seekhe gaye.

Embedding kya hai?
A learned lookup table that maps each token id to a dense vector. Tokens used in similar contexts end up with similar vectors.

4096 × 384 ki ek table. Row number = token id.

B. Attention

Self-attention samjhao.
Each token builds a query, a key and a value. The score between two tokens is the dot product of one's query and the other's key. Softmax turns scores into weights, and the output is the weighted sum of values.

Query = sawaal, key = label, value = maal. Jiski key meri query se mile, uska maal mujhe zyada.

√d se bhaag kyun dete hain?
Dot products grow with dimension. Large scores push softmax into saturation where gradients vanish. Scaling keeps the variance around one.

Bina iske softmax ek hi token ko sab kuch de deta hai aur seekhna ruk jaata hai.

Multi-head kyun?
One head can only express one attention pattern. Multiple heads let the model attend to different relations in parallel at the same total cost.

Hamare 6 heads, har ek 64 dimension ka. 6 × 64 = 384.

Causal mask kyun zaroori hai?
It stops a position from seeing future tokens. That lets us train on every position of a sequence in one forward pass without leaking the answer.

Bina mask ke model agla token dekh ke copy kar leta, kuch nahi seekhta. Hamara test ise check karta hai.

Position ki jaankari kaise dete ho? RoPE kya hai?
Attention is permutation-invariant, so position must be injected. RoPE rotates query and key vectors by an angle proportional to position, so their dot product depends only on relative distance.

Purana tareeka: har position ka seekha hua vector jodna. RoPE mein alag table nahi chahiye.

Attention ki complexity kya hai?
Quadratic in sequence length, O(T²), because every token attends to every earlier token. That is why context windows are expensive.

256 tokens = 65,536 pair. 2,560 tokens = 100 guna zyada.

C. Architecture

Residual connection kyun?
It gives gradients a direct path through the network, so deep stacks train. Each block only has to learn a correction to its input.

x = x + f(x). Bina iske 6 layers ke baad gradient lagbhag gayab ho jaata.

Normalization kyun? Pre-norm aur post-norm mein fark?
Normalization keeps activation scale stable. Pre-norm applies it before each sub-layer so the residual path stays an identity, which trains more stably than the original post-norm.

Hamne RMSNorm liya: LayerNorm bina mean aur bias ke.

Feed-forward layer ka kya kaam hai?
Attention mixes information across tokens; the feed-forward layer transforms each token independently. It holds most of the parameters.

Hamare model mein 7.08 M of 12.2 M parameters feed-forward mein hain.

Weight tying kya hai?
The input embedding and the output projection share one matrix. It saves parameters and usually helps small models.

1.57 M parameters bache. nanochat ise nahi karta, kyunki bade model mein alag rakhna behtar nikla.

GPT aur BERT mein fark?
GPT is decoder-only with causal attention, trained to predict the next token, so it generates. BERT is encoder-only with bidirectional attention, trained on masked tokens, so it is for understanding.

Hamara model GPT jaisa hai. STT ke module mein encoder milega.

D. Training

Loss function kya hai?
Cross-entropy: the negative log probability the model assigned to the correct next token, averaged over all positions.

Sahi token ko 90% diya to loss 0.1; 1% diya to 4.6.

Training shuru karte hi kya check karte ho?
That the initial loss is about ln of the vocabulary size. For 4096 that is 8.32, and I got 8.37. If it is far off, there is a bug in the model or the data.

Sabse sasta aur sabse kaam ka check.

Perplexity kya hai?
The exponential of the loss. It reads as the effective number of choices the model is uncertain between. Mine is 6.5.

Random model ka 4,096 hota.

AdamW kyun, SGD kyun nahi?
Adam keeps a per-parameter step size from running gradient statistics, which transformers need because gradient scales differ a lot between layers. The W means weight decay is applied directly to the weights instead of through the gradient.

Weight decay sirf matrices pe lagaya, norm ke gains pe nahi.

Warmup aur cosine decay kyun?
Early gradients from a random network are noisy, so we ramp the learning rate up. Then we decay it so the model settles into a minimum instead of bouncing around.

200 step warmup, phir 6e-4 se 6e-5 tak.

Overfitting kaise pakdi?
I hold out 2% of documents and compare training and validation loss. If training keeps dropping while validation rises, it is memorizing. In my run the gap stayed at 0.19.

Aur sabse achhe val loss wala checkpoint hi save hota hai.

E. Inference

Temperature, top-k, top-p samjhao.
Temperature rescales logits to make the distribution sharper or flatter. Top-k keeps the k most likely tokens. Top-p keeps the smallest set whose cumulative probability reaches p, so it adapts to the model's confidence.

Chapter 6 ka chart dekho: wahi prompt, teen temperature.

KV cache kya hai?
During generation the keys and values of earlier tokens never change, so we cache them and only process the new token. It turns each step from re-reading the whole sequence into one token's work.

Is machine pe {{KV_X}}x tez, aur test ye pakka karta hai ki output wahi hai.

Model galat baat kyun bolta hai (hallucination)?
It is trained to produce likely text, not true text. It has no mechanism to check facts, so a fluent wrong continuation is as valid to it as a correct one.

Hamare model mein ye saaf dikhta hai: grammar sahi, kahani ka logic toota hua.

F. Fine-tuning aur deployment

LoRA kya hai? Full fine-tuning se behtar kyun?
LoRA freezes the base weights and trains a low-rank update. It needs far less memory and storage, and one base model can serve many small adapters.

Hamara adapter 0.45 MB, poora model 48.8 MB.

LoRA mein B ko zero se kyun shuru karte hain?
So that B times A is zero at the start and the model behaves exactly like the pretrained one. Training then moves away from that smoothly.

Hamara test: naya adapter lagane pe output bilkul same.

Catastrophic forgetting kya hai? Tumne dekha?
When fine-tuning on new data damages what the model already knew. I saw general validation loss rise from 2.70 to 3.19, and reduced it by mixing a batch of original data into each step.

Is technique ko replay ya rehearsal kehte hain.

Quantization kya hai? Kitna nuksaan hua?
Storing weights in fewer bits. int8 cost nothing on my model, 4-bit per-channel cost 0.03 in loss, and 2-bit collapsed.

Per-channel = har row ka apna scale. 4-bit pe ye per-tensor se 4 guna behtar tha.

G. Project ke baare mein

Kaise pata ki tumhara code sahi hai?
I wrote tests for the properties that must hold: changing a future token does not change earlier logits, the KV cache gives identical logits to a full pass, my cross-entropy matches PyTorch's, and a fresh LoRA adapter is a no-op.

Loss girna kaafi nahi; galat model bhi kuch na kuch seekh leta hai.

Sabse mushkil ya dilchasp bug kaunsa tha?
Quantization showed zero change in loss, which looked like a bug. I measured the actual weight error and found int8 was only about 1% off, so the result was real. I then pushed to 4, 3 and 2 bits to find where it breaks.

Seekh: "kuch nahi badla" ko pehle shak se dekho, phir naap ke maano.

nanoGPT se alag kya kiya?
nanoGPT reproduces GPT-2. Mine uses the modern stack: RoPE, RMSNorm, SwiGLU. I also wrote the tokenizer, added language control tokens for Hindi, Marathi and Hinglish, a KV cache, LoRA, quantization measurements and an attention inspector.

Aur ek ablation study jo nanochat ke do ideas ko naapti hai.

Kya ye production mein use ho sakta hai?
No. With 12 million parameters and 11 million tokens it writes simple stories and short chat, not facts or reasoning. Its purpose was understanding. For real use I would fine-tune an existing model.

Ye sachcha jawab hai, aur ye tumhe samajhdaar dikhata hai.

Aage kya karoge?
Run the QK-norm and zero-init variant for the full length with multiple seeds, add more data since validation loss was still falling, add a chat fine-tuning stage with role tokens, and build a fixed evaluation set beyond loss.

Phir STT, TTS aur orchestration, isi tarah scratch se.
